# StallSeeker banner - editable asset pack

This is a faithful editable recreation of the generated banner concept, not an extraction of original design layers. The original AI-generated image is a flat raster and did not contain a font file or editable objects. Small differences in the recreated logo background, lettering, phone placement and food are intentional consequences of the rebuild.

## Start here
- 01-POSTER/StallSeeker-banner-editable.svg: complete self-contained SVG, with editable text, grouped layers and embedded fonts/images. Artboard is exactly 609.6 x 1524 mm (2 x 5 ft).
- 01-POSTER/StallSeeker-banner-outlined.svg: same design with text converted to real Bezier paths; no font installation needed for appearance. Screenshots and food remain embedded raster images.
- 01-POSTER/StallSeeker-vector-only-template.svg: genuinely vector-only; has illustrated food and clearly labelled empty phone screens for inserting your own screenshots. Text is outlined. No raster images.
- 01-POSTER/StallSeeker-banner-2x5ft.pdf: full-size vector PDF export with embedded screenshots and photographic food. RGB working file, trim size, no bleed or crop marks. Ask the printer to apply their required bleed, lower stand allowance and color conversion.
- 01-POSTER/banner-preview.png: preview, not a full-resolution print export.
- 01-POSTER/original-generated-concept.png: the exact original image shown in chat.

## Separate visuals
02-VECTOR-ASSETS includes the logo icon, white logo mark, wordmark, four feature icons, storefront icon, accent rays, cream map background, dotted route, orange pill labels, vendor panel, footer wave, phone frame, headline, footer text, QR placeholder and a vector nasi lemak illustration. SVGs with '-outlined' contain text converted to paths. 'phone-...-with-screenshot.svg' are hybrid SVG wrappers around raster screenshots, not vectorized app screens.

03-RASTER-ASSETS includes the source app logo, original JPG phone screenshots, rounded-corner transparent PNG phone screenshots and a transparent nasi lemak cutout. The food cutout was isolated/regenerated from the concept using image generation, so it is not pixel-identical to the small food image in the original. The separate vector food illustration is a stylized alternative, not a photographic trace.

04-FONTS includes Poppins Regular, Medium, SemiBold, Bold, ExtraBold and Black TTF files with the original SIL Open Font License. Poppins is the chosen matching font for this rebuild; the generated concept's exact font cannot be identified or extracted. Install the fonts before editing the live text SVG in desktop design software.

## Font usage in this rebuild
- Wordmark: Poppins Bold (700).
- Large headline: Poppins Black (900).
- Supporting text: Poppins Regular (400).
- Screenshot labels and feature headings: Poppins SemiBold (600).
- Vendor heading: Poppins SemiBold (600).
- Footer headline: Poppins Bold (700).
- CTA and eyebrow: Poppins Medium (500).
- ExtraBold (800) is included as an optional alternate weight.

POSTER-TEXT.txt contains all copy. COLORS.json contains the exact RGB colors.

## Editing and print
Open the SVG in Inkscape, Illustrator or another SVG-capable editor. Elements are grouped by purpose; Inkscape layers have readable names. Canva import may flatten or alter groups, fonts and filters, so use the outlined SVG or import separate assets if needed.

The full-size SVG artboard is vector-scalable. Raster image detail is limited to the supplied source resolution; use fresh higher-resolution app screenshots for final printing if needed. This pack does not turn raster screenshots into true vector interfaces.

The DEMO QR box is intentionally a placeholder and does not scan. Replace it with the real QR before printing. Nothing has been published or sent to a printer.

The generated concept used the built-in image-generation tool. The SVGs are locally rebuilt editable artwork. Only the food cutout was processed again with the built-in image-generation tool. The app logo and screenshots come from this project. Font redistribution follows the included OFL.txt.
